## 문제 1. 구간 온도차

연속된 `N`일의 기온이 기록되었다. 정확히 `K`일을 연속해서 고른 모든 구간의 합을 구할 수 있다. 그중 **가장 큰 합과 가장 작은 합의 차이**를 출력하라. 구간은 순서를 유지한 채 길이 `K`만큼 잘라야 하며, 임의의 날을 건너뛸 수 없다. 같은 합을 갖는 구간이 여러 개 있어도 차이는 한 번만 계산한다.

**입력:** 각 테스트 케이스는 `N K` 한 줄과 정수 `N`개 한 줄로 구성된다. `1 ≤ T ≤ 20`, `1 ≤ K ≤ N ≤ 100,000`, 각 기온은 `-1,000` 이상 `1,000` 이하이다.

**출력:** `#번호 최대구간합-최소구간합`. `K=N`이면 구간이 하나뿐이므로 답은 0이다.

```txt
입력
2
8 3
2 1 5 1 3 2 4 1
5 2
-3 -1 -4 2 0

출력
#1 3
#2 7
```

첫 번째 배열의 길이 3 구간 합은 차례대로 `8, 7, 9, 6, 9, 7`이므로 `9-6=3`이다. 두 번째 배열의 길이 2 구간 합은 `-4, -5, -2, 2`이므로 `2-(-5)=7`이다. 음수가 있으므로 최댓값을 무조건 0으로 초기화하면 틀릴 수 있다.

**직접 확인:** `K=1`, `K=N`, 모든 수가 음수, 같은 최댓값이 여러 번 나오는 경우.

## 문제 2. 십자 모양 꽃가루 조사

`N × M` 격자의 각 칸에 꽃가루 양이 적혀 있다. 조사 장치를 한 칸 `(r,c)`에 설치하면 **중앙 칸 1개와 상·하·좌·우 방향으로 각각 최대 ****`K`****칸**의 꽃가루를 합산한다. 격자 밖으로 넘어가는 칸은 세지 않는다. 한 칸은 한 번만 세며, 대각선 칸은 포함하지 않는다.

모든 칸을 설치 위치로 시도한 뒤 가장 큰 합과 그 위치를 구하라. 최대 합이 같은 위치가 여러 개면 **행 번호가 작은 곳, 그다음 열 번호가 작은 곳**을 택한다. 좌표는 0부터 시작한다.

**입력:** 각 테스트 케이스는 `N M K` 한 줄과 공백으로 구분된 정수 `M`개가 담긴 `N`줄로 구성된다. `1 ≤ T ≤ 20`, `1 ≤ N,M ≤ 50`, `0 ≤ K ≤ 10`, 각 꽃가루 양은 `0` 이상 `100` 이하이다.

**출력:** `#번호 최대합 행 열`.

```txt
입력
2
3 4 1
1 2 3 4
0 5 0 1
2 1 4 0
2 2 2
0 0
0 0

출력
#1 13 1 2
#2 0 0 0
```

첫 번째 격자에서 `(1,2)`를 중심으로 하면 중앙 `0`, 위 `3`, 아래 `4`, 왼쪽 `5`, 오른쪽 `1`의 합이 `13`이다. 두 번째 격자는 모든 위치의 합이 0이므로 가장 앞 좌표인 `(0,0)`을 고른다.

**직접 확인:** `K=0`, 한 칸 격자, 직사각형 격자, 가장자리 중심, 동점 위치.

## 문제 3. 스택 추적 서술

문자열에서 일반 문자 `A`부터 `Z`까지는 무시하고 괄호 `()`, `[]`, `{}`만 검사한다. 여는 괄호는 스택에 넣는다. 닫는 괄호가 나오면 **스택 맨 위의 여는 괄호**와 짝이 맞아야 한다. 맞지 않거나 스택이 비어 있으면 즉시 실패한다. 마지막에 스택이 남아 있어도 실패다.

`A{B[CD](E)}F`와 `([)]`를 각각 검사할 때, ① 괄호를 처리한 뒤의 스택 상태를 순서대로 적고, ② 성공·실패와 실패 시 첫 실패 위치를 적고, ③ 스택을 쓰는 이유를 설명하라. 위치는 **원본 문자열의 0부터 시작하는 인덱스**이며, 스택 표기는 왼쪽이 바닥, 오른쪽이 맨 위다.
