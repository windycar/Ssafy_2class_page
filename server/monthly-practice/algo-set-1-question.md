## 문제 1. 연속해서 커지는 당근

당근의 크기가 수확 순서대로 주어진다. 배열에서 이웃한 두 당근을 비교하여, 뒤의 당근이 앞의 당근보다 **엄격하게 큰** 경우에만 같은 증가 구간으로 묶는다. 같은 크기이거나 더 작아지면 그 위치에서 새 구간이 시작된다. 여러 증가 구간 중 길이가 가장 긴 구간의 **당근 개수**를 구하라. 배열에서 떨어진 위치의 당근을 건너뛰어 이어 붙일 수 없다.

첫 줄에 테스트 케이스 수 `T`가 주어진다. 각 테스트 케이스는 한 줄의 `N`과 다음 줄의 크기 `N`인 정수 배열이 차례로 주어진다. `1 ≤ T ≤ 20`, `1 ≤ N ≤ 100,000`, 각 크기는 `1` 이상 `1,000,000` 이하이다. 각 테스트 케이스에 대해 `#번호 최대길이`를 출력한다. 길이가 1인 구간도 유효하므로 답은 최소 1이다.

```txt
입력
3
6
2 3 4 1 5 6
5
7 7 7 7 7
7
1 2 3 4 5 6 7

출력
#1 3
#2 1
#3 7
```

첫 번째 경우 증가 구간은 `[2, 3, 4]`, `[1, 5, 6]`으로 나뉘어 최대 길이가 3이다. 두 번째 경우 같은 값은 증가로 인정하지 않아 길이가 모두 1이다.

확인할 경계 사례: `N=1`, 모두 같은 값, 모두 감소, 가장 긴 구간이 배열 끝에서 끝나는 경우.

## 문제 2. 섬의 개수와 가장 큰 섬

`N × M` 격자에서 `1`은 땅, `0`은 바다이다. 땅 두 칸이 **상하좌우**로 붙어 있으면 서로 연결된다. 이 연결을 여러 번 따라가서 도달할 수 있는 모든 땅 칸이 하나의 섬이다. 대각선으로만 닿은 땅은 별개 섬이다. 테스트 케이스마다 섬의 개수와 가장 큰 섬의 칸 수를 구하라. 땅이 없으면 `0 0`을 출력한다.

첫 줄에 `T`가 주어진다. 각 테스트 케이스는 `N M` 다음에 `N`줄의 `0`과 `1`이 **공백으로 구분되어** 주어진다. `1 ≤ T ≤ 20`, `1 ≤ N, M ≤ 100`이다. 행 번호는 위에서 아래로, 열 번호는 왼쪽에서 오른쪽으로 증가한다. 각 테스트 케이스에 대해 `#번호 섬개수 최대크기`를 출력한다.

```txt
입력
2
4 5
1 1 0 0 1
0 1 0 1 1
1 0 0 0 0
1 1 0 1 0
3 3
0 0 0
0 0 0
0 0 0

출력
#1 4 3
#2 0 0
```

첫 번째 격자에는 크기 3인 섬이 세 개, 크기 1인 섬이 한 개다. 따라서 섬의 수는 4, 최대 크기는 3이다. 두 번째 격자에는 땅이 없다.

확인할 경계 사례: 땅이 없음, 땅 한 칸, 대각선으로만 닿음, 직사각형 격자, 여러 갈래로 연결된 섬.

## 문제 3. BFS 과정 서술

다음 무방향 그래프에서 `A`부터 BFS를 수행한다. 인접 정점은 적힌 **왼쪽부터** 확인하며, 방문 표시는 큐에 넣을 때 한다.

```txt
A: B C
B: A D E
C: A F
D: B
E: B F
F: C E
```

다음 세 가지를 서술하라. 큐 상태는 **왼쪽이 다음에 꺼낼 정점**, 오른쪽이 나중에 넣은 정점이라고 정한다. 한 정점의 이웃을 모두 확인한 뒤의 상태를 적는다.

1. 정점을 큐에서 꺼내는 순서.
2. 각 정점을 꺼낸 직후 새 정점을 추가한 다음의 큐 상태.
3. BFS가 큐를 쓰는 이유와 방문 표시를 큐에 넣을 때 해야 하는 이유.

**추가 암기 점검:** 루트가 `1`, 왼쪽 자식이 `2`, 오른쪽 자식이 `3`, `2`의 왼쪽·오른쪽 자식이 각각 `4`, `5`인 트리의 전위·중위·후위 순회를 적어 본다. 이는 위 3문항에 포함되지 않는 추가 연습이다.
