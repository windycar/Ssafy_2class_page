## 추가 1. 잡초에서 떨어진 공

한 줄의 들판에는 공 `B`, 잡초 `W`, 빈칸 `.`이 있다. 로봇은 위치 `i`의 공을 주우려 할 때 인덱스 차이가 `D` 이하인 곳에 잡초가 하나라도 있으면 그 공을 포기한다. 즉, 구간 `[i-D, i+D]`와 격자가 겹치는 부분에 `W`가 없어야 그 공을 주울 수 있다. 주울 수 있는 공의 수를 구하라. 들판 밖은 무시한다.

**입력:** 각 테스트 케이스는 `N D` 한 줄과 길이 `N`인 `B`, `W`, `.` 문자열 한 줄로 구성된다. `1 ≤ T ≤ 20`, `1 ≤ N ≤ 100,000`, `0 ≤ D < N`. **출력:** `#번호 주울수있는공개수`.

```txt
입력
2
9 1
BB.WB..BB
6 2
WB.BBW

출력
#1 4
#2 0
```

첫 번째 들판의 잡초는 인덱스 3에 있어 인덱스 4의 공만 포기한다. 두 번째 들판의 공 세 개는 모두 어느 잡초에서 2칸 이내에 있다. 이는 SWEA 14555의 원문이 아니라 **1차원 문자 순회 연습용 창작 변형**이다.

## 추가 2. 가로·세로 회문 수

`N × M` 문자 격자에서 정확히 길이 `L`인 연속 문자열을 **가로 왼쪽→오른쪽** 또는 **세로 위→아래**로 잘라낸다. 앞에서 읽어도 뒤에서 읽어도 같은 문자열이면 회문 1개로 센다. 시작 위치가 다르면 겹쳐도 각각 센다. 가로와 세로에서 우연히 같은 문자열이 나와도 방향이 다르면 각각 센다.

**입력:** 각 테스트 케이스는 `N M L` 한 줄과 대문자 `M`개로 이루어진 문자열 `N`줄로 구성된다. `1 ≤ T ≤ 20`, `1 ≤ N,M ≤ 20`, `2 ≤ L ≤ max(N,M)`. 한 방향의 길이가 `L`보다 짧으면 그 방향에서는 검사할 구간이 없다. **출력:** `#번호 회문개수`.

```txt
입력
2
3 3 3
ABA
BAB
ABA
2 2 2
AA
AA

출력
#1 6
#2 4
```

첫 번째 격자는 세 행과 세 열이 각각 회문이므로 6개다. 두 번째 격자는 가로 2개와 세로 2개를 따로 센다.

## 추가 3. 날짜별 남은 구역

`N × N` 격자의 각 칸에는 높이 `1`부터 `K`까지의 수가 있다. 날짜 `d`에는 높이가 **`d`****보다 큰 칸만** 남는다. 남은 칸들이 상하좌우로 연결되면 하나의 구역이다. 날짜 `0,1,...,K`를 각각 독립적으로 조사해 구역 수의 최댓값과 그 최댓값이 처음 나타난 날짜를 구하라. 남은 칸이 없는 날짜의 구역 수는 0이다.

**입력:** 각 테스트 케이스는 `N K` 한 줄과 공백으로 구분된 높이 `N`개가 담긴 `N`줄로 구성된다. `1 ≤ T ≤ 20`, `1 ≤ N ≤ 20`, `1 ≤ K ≤ 10`. **출력:** `#번호 최대구역수 가장이른날짜`.

```txt
입력
2
3 3
3 1 3
1 3 1
3 1 3
2 1
1 1
1 1

출력
#1 5 1
#2 1 0
```

첫 번째 격자는 날짜 0에 한 구역이지만, 날짜 1에는 대각선으로만 닿는 높이 3의 다섯 칸이 남아 **다섯 구역**이 된다. 날짜 1과 2가 동점이므로 1을 고른다. SWEA 7733의 핵심인 **기준 변경 후 연결 요소 다시 세기**를 연습하는 창작 변형이며, 기본 2시간 세트보다 도전적인 문제다.
