
# SSAFY 광주 2반 랜덤 팀 편성

교육생 명단에서 참여자를 선택하고 팀 수 또는 팀당 인원수에 맞춰 랜덤으로 팀을 편성하는 웹페이지입니다.

## 로컬 실행

```bash
pnpm install
pnpm dev
```

## 프로덕션 빌드

```bash
pnpm build
pnpm preview
```

## Netlify 배포

저장소를 Netlify에 연결하면 `netlify.toml` 설정에 따라 자동으로 빌드됩니다.

- 빌드 명령: `pnpm build`
- 배포 폴더: `dist`
- Node.js: 22
